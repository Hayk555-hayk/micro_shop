# Marketplace Project 🛒

> **Note:** This is an educational project created to practice and demonstrate full-stack software development skills.

---

## 📌 About the Project

This repository contains a fully functional marketplace web application designed as an educational project. The primary goal of this project was to build a modern e-commerce platform from scratch, focusing on scalability, clean architecture, and standard web development best practices.

### Key Features
- **User Authentication & Roles:** Secure sign-up/login system with different access levels (Buyers, Sellers, and Admins).
- **Product Catalog:** Browse products with search, filtering, and sorting capabilities.
- **Shopping Cart & Checkout:** Add products to a cart, manage items, and simulate an order checkout flow.
- **Seller Dashboard:** Allow vendors to add, update, and manage their product listings.
- **User Profiles & Order History:** Track current orders and past purchase history.
